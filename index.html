🔁 How to activate background reminders

Everything below is done entirely in your browser — no terminal or command line needed.

Step 1 — Create the Edge Function in Supabase
  1. Go to supabase.com → open your project
  2. Click Edge Functions in the left sidebar
  3. Click "Create a new function"
  4. Name it send-reminders
  5. Delete the placeholder code and paste in the entire contents of
    supabase/functions/send-reminders/index.ts from this repo
  6. Click Deploy
Step 2 — Add your Resend API key as a secret
  1. Still in Supabase, click Edge Functions → Secrets (top tabs)
  2. Click "Add new secret"
  3. Name: RESEND_API_KEY   Value: your re_... key
  4. Click Save
Step 3 — Schedule it inside Supabase (no external services)
  1. In your Supabase project, click Cron Jobs in the left sidebar
  2. Click "Create a new cron job"
  3. Give it a name like finflow-daily-reminders
  4. Set the schedule to 0 9 * * * (every day at 9 AM UTC)
  5. For the function to run, select Edge Function and pick send-reminders
  6. Click Create — that's it, fully automatic from now on
The cron schedule 0 9 * * * means 9 AM UTC every day. To change the time, just edit the number — e.g. 0 14 * * * = 2 PM UTC = 9 AM Eastern.
